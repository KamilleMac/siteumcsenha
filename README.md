# Senha fraca abre a porta

Site informativo sobre senhas fracas: por que elas são perigosas, como criar uma senha forte e o que fazer se descobrirem a sua.

**Site no ar:** https://siteumcsenha.vercel.app

## Sobre o projeto

Trabalho da faculdade, feito como atividade de **horas de extensão**. O objetivo é ajudar a população, principalmente pessoas mais velhas, a reconhecer e evitar golpes digitais, com linguagem simples e visual fácil de entender.

- **Universidade:** Universidade de Mogi das Cruzes (UMC)

## O que tem no site

- Por que senha fraca é perigosa e como a invasão acontece, em 3 passos
- Senhas para evitar
- "Entenda cada palavra": o que é senha forte, frase-senha, verificação em duas etapas, gerenciador de senhas, vazamento de dados e phishing
- Números oficiais de golpes digitais no Brasil
- Como criar uma boa senha e passo a passo na tela
- Passo a passo para trocar a senha e ativar a verificação em duas etapas no WhatsApp, Instagram, Facebook, Gmail e app do banco
- Como combater e como ajudar outras pessoas
- O que fazer se descobriram a sua senha
- Panfleto (frente e verso) para imprimir

## Tecnologias

HTML, CSS e JavaScript puros, sem bibliotecas. O site é responsivo (funciona no celular e no computador) e foi publicado na Vercel.

## Como ver no computador

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
